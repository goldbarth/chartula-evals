### What's New

- **Inline citation badges:** Answers from the assistant now show numbered citation badges right after the cited passage title, with a tooltip on hover or focus showing the title, source, heading and snippet. Each badge shares its number with the entry in the Sources list, so you can match a claim to its source without searching. Badges appear only when the answer quotes the passage title as written; a citation whose title is missing stays in the Sources list.
- **Suggested next step button:** The ticket header now shows the most likely next step as a button that runs it, such as assigning an owner or moving the ticket to the next status, with the remaining steps in an overflow menu. You can rely on the button doing the same thing as the manual controls, so you no longer have to open them for the suggested step. Steps that cannot be run are shown as plain text, and a ticket with no suggestions keeps the existing controls.
- **Command palette:** Pressing Ctrl+K (Cmd+K on Mac) on any page opens a command palette, even while a text field has focus. It lists navigation targets and matching tickets as you type, so you can reach a page or ticket without the mouse. Use the arrow keys to move, Enter to open and Esc to close, which returns focus to where you were.
- **Instant status changes:** Changing a ticket's status on the board or the detail view now shows the new status immediately, instead of a dragged card snapping back until the server answers. If the server rejects the change, the previous state is restored and a message shows the error code, so you can see why it was refused. Two quick changes to the same ticket will not leave the board showing a status the server did not accept.
- **Inline status and assignee edits:** Change Status and Assign now open as small menus in the ticket header instead of dialogs. The change applies when you pick an item, so you stay on the same ticket, scroll position and tab. The assignee menu includes an Unassigned option and marks the current assignee, and errors appear as a message.
- **Citation badges in chat:** Assistant answers can show numbered citation badges with a tooltip on hover or keyboard focus giving source, heading and snippet. Citations not anchored in the text stay in a numbered sources list, so every source remains visible. An answer without citations shows no empty sources block.
- **Assigning tickets by agent name:** The assistant invented an agent name when asked to assign a ticket, because it could not see the list of agents. It now has the current agent roster with every request, so it uses only names on that list. If the name you give is not on it, it lists the valid agents instead of choosing the closest match.
- **Grounding check enforced:** A knowledge-base answer could be shown without its grounding check having run, and nothing indicated this. The assistant is now required to run the check once after it retrieves knowledge-base passages, before it starts the answer. This guarantees at least one check after retrieval, not that every passage in a long chain was checked.
- **Consistent visual design:** Colours, spacing, corner radius and status and priority chip colours now come from one shared set of values across the web app. The status and priority chips, which had drifted apart between the queue, board and detail views, now look the same everywhere. Spacing and corner sizes move by one to four pixels in places as they snap to the shared scale, and board card titles are no longer cut off mid-letter.

### What's Changed

- **Version 1.9.0 release:** Version 1.9.0 brings the full Frontend Redesign into one release. Assistant answers render as formatted text with citations in a sources list below, the send button sits inside its panel, and grounding scores no longer appear in the chat transcript.

### Bug Fixes

- **Board card titles:** Long ticket titles on board cards could grow the card without limit in some older Chrome versions. Titles are now limited to two lines with an ellipsis, so cards in a lane keep a consistent height. Newer Chrome versions were not affected.
- **Assistant send button:** In the assistant chat, the send button sat flush against the panel's right edge and hung over it. The panel now has its intended padding, so the button stays inside the panel and lines up with the input at any width, and messages scroll inside the panel with the composer kept at the bottom.
- **Queue column headers:** In the ticket queue, the Category header overlapped the Due header and read as "CategoryUE". Category now has its own column width and uppercase styling like the other headers, so the headers read side by side and line up with their cells. Category is a plain label, not a sort option.
- **Honest changes and fewer confirmations:** The assistant could say a change was made without confirming a result, and could ask again for changes you had already requested. It is now told to report a change only after the tool call succeeded in the conversation. It is also told to make requested changes without re-asking, and to ask only when a ticket match is ambiguous, information is missing, an action is hard to reverse with real doubt about intent, or a routing suggestion is uncertain.
- **Summary timestamps:** Times in streamed ticket summaries appeared in UTC, so a comment written at 12:07 local time showed as 10:07. Summaries now use the configured user time zone, so times match the ticket detail view and due dates carry your offset.
- **Knowledge-base search failures:** A failed knowledge-base search was reported as a normal search result, so it was counted as healthy on the dashboard. It is now reported as an error, separate from the case where the knowledge base is unavailable. The dashboard error rate now reflects real failures.
- **Grounding by meaning:** The assistant's grounding check marked correct paraphrases, translations and hedged answers as ungrounded, because it only compared words. It now compares meaning, so such answers are scored as supported by the source passage. Without a Voyage key or if the meaning-based check fails, it falls back to word comparison.
