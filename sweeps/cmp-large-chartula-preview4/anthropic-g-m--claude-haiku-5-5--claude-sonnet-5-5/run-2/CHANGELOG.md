## 0.1.0-preview.4 - 2026-10-07

### Changed

- This release will bump the NuGet minor-and-patch dependency group: Anthropic from 12.49.0 to 12.53.0, coverlet.collector from 10.0.1 to 10.1.0, and Microsoft.Extensions.AI.OpenAI from 10.10.0 to 10.10.1. ([#328](https://github.com/goldbarth/chartula/pull/328))

### Added

- **Breaking:** This release will stop writing the change descriptions into `changelog.json`, which becomes schema version 2 and no longer carries a `description` on each change; the complete facts, descriptions included, move to a new optional `facts` array in the run record, which reads back through `RunRecordJsonSerializer.DeserializeFactBase`. ([#294](https://github.com/goldbarth/chartula/pull/294))
- **Breaking:** This release will make `preview` free of model calls: it lists each fact with the audiences that render it, each dropped change with the setting that dropped it, and the number of model calls and prompt characters `generate` would send, and it no longer needs a model key. ([#292](https://github.com/goldbarth/chartula/pull/292))
- This release will show the audience name as a heading above each rendering, put the run's outcome in the first line of the summary, and open each command's output with a header naming the command. ([#342](https://github.com/goldbarth/chartula/pull/342))
- This release will group the output of `doctor` into Repository, Model and GitHub sections, mark each check's status with a symbol and a word, and state in its closing line whether a run would start or stop. ([#341](https://github.com/goldbarth/chartula/pull/341))
- This release will show a spinner with the current step's count and elapsed time while a run works on a terminal, and add the `--plain` option to every command to turn off colour and motion. ([#340](https://github.com/goldbarth/chartula/pull/340))
- This release will quote each pull request's title and description between tags in the prompts, instruct the model to treat that text as material rather than instructions, and cut descriptions longer than 8,000 characters. ([#338](https://github.com/goldbarth/chartula/pull/338))
- This release will stop `generate` before its first model call when a release already exists as published, unless `--replace-published` is passed, and will check the same condition again before writing. ([#335](https://github.com/goldbarth/chartula/pull/335))
- This release will show the location of this version's configuration template when `doctor` finds no `chartula.yaml`. ([#329](https://github.com/goldbarth/chartula/pull/329))
- This release will show each step of a run as it works, with a line per step on a terminal that updates its time while a model call runs, and one plain line per step where there is no terminal. ([#297](https://github.com/goldbarth/chartula/pull/297))
- This release will add the `chartula doctor` command, which checks git, the checkout, the tag, the repository, the configuration, the model endpoint, GitHub read and write access, and pull request titles before a run, and exits with 1 if a check fails. ([#295](https://github.com/goldbarth/chartula/pull/295))
- This release will take the closed issue numbers from the title and description at every fact depth, so `factBase.depth: title-description-and-issues` now reads as `title-and-description`, and older values are still accepted. ([#293](https://github.com/goldbarth/chartula/pull/293))
- This release will render commits that belong to no merged pull request as changes of their own and skip merge commits in a release that has no pull requests, and will report the counts of these commits in the run summary and run record. ([#291](https://github.com/goldbarth/chartula/pull/291))
- This release will add `chartula --version`, which prints the installed version and exits with 0. ([#286](https://github.com/goldbarth/chartula/pull/286))
- This release will render a first tag from the first commit by default, with `--whole-history` no longer needed, and will ask for confirmation before a first tag or a range above `range.confirmAboveCommits` commits is read, with `--yes` to confirm up front. ([#282](https://github.com/goldbarth/chartula/pull/282))

### Fixed

- This release will list each option of `chartula --help` once under its group, with `--replace-published` under the group for what a run writes, and will update the roadmap. ([#344](https://github.com/goldbarth/chartula/pull/344))
- This release will compare the names the rule-based faithfulness check looks up with whitespace folded and code fences removed, so names wrapped over lines or inside fenced blocks are no longer flagged when the facts contain them. ([#336](https://github.com/goldbarth/chartula/pull/336))
- This release will write the sentence "This release has no features, fixes, performance improvements or breaking changes." into `CHANGELOG.md` and the release notes when a release has nothing for the technical reader, while `changelog.json` keeps the empty rendering. ([#333](https://github.com/goldbarth/chartula/pull/333))
- This release will write `changelog.json` and the run record with only the characters JSON requires escaped, so backticks, quotes and non-ASCII text are readable in the files. ([#332](https://github.com/goldbarth/chartula/pull/332))
- This release will set the flags of a rendering apart after a blank line under a heading, instead of printing them indented under its last entry. ([#331](https://github.com/goldbarth/chartula/pull/331))
- This release will show "unauthenticated" with the name of the unset credential variable in the run header when no GitHub token or model key is set, instead of naming a token source. ([#330](https://github.com/goldbarth/chartula/pull/330))
- This release will refuse an option a command does not take, a value option without a value and a repeated single-value option, and will honour `-h` and `--help` wherever they appear after a command. ([#301](https://github.com/goldbarth/chartula/pull/301))
- This release will append the trailing slash to a GitHub API URL set without one, so `Chartula__GitHub__ApiBaseUrl` works with or without it. ([#290](https://github.com/goldbarth/chartula/pull/290))
- This release will read an empty `filter.excludeCategories` list as dropping no category, instead of keeping the default, both in the file and in the environment variable. ([#289](https://github.com/goldbarth/chartula/pull/289))
- This release will report a model answer that the SDK cannot read as unreadable, with the value it could not read, instead of as an endpoint that could not be reached. ([#288](https://github.com/goldbarth/chartula/pull/288))
- This release will refuse a run when both `chartula.yaml` and `chartula.yml` exist in the directory, naming both paths and how to resolve it. ([#287](https://github.com/goldbarth/chartula/pull/287))
- This release will check before the first model call that the token may publish release notes, so a run with a token that cannot publish stops early with the reason and the run's options. ([#285](https://github.com/goldbarth/chartula/pull/285))
- This release will describe `--no-publish` in the help text as writing every file while publishing no GitHub release notes. ([#284](https://github.com/goldbarth/chartula/pull/284))
