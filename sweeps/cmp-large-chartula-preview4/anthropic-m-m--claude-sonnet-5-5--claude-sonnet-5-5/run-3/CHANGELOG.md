## 0.1.0-preview.4 - 2026-10-07

### Changed

- Update `Anthropic` from 12.49.0 to 12.53.0, `coverlet.collector` from 10.0.1 to 10.1.0, and `Microsoft.Extensions.AI.OpenAI` from 10.10.0 to 10.10.1. ([#328](https://github.com/goldbarth/chartula/pull/328))

### Added

- **Breaking:** Remove `description` from the `changelog.json` change entries (schema version 2) and keep the complete facts, descriptions included, in a new `facts` array of the run record. ([#294](https://github.com/goldbarth/chartula/pull/294))
- **Breaking:** Make `preview` free of model calls: stop it once the facts are complete, then print each fact with its audiences, each dropped change with the setting that dropped it, and the calls and prompt characters `generate` would send. ([#292](https://github.com/goldbarth/chartula/pull/292))
- Open each run's summary on a first line stating how the run went, add a `chartula · generate` or `chartula · preview` header, use audience headings, and group the help text. ([#342](https://github.com/goldbarth/chartula/pull/342))
- Group the `doctor` checks into Repository, Model and GitHub, mark each status with a symbol and a word, and make the closing verdict count warnings and say whether a run would start or stop. ([#341](https://github.com/goldbarth/chartula/pull/341))
- Show run progress with the Quiet Pulse spinner on a terminal, and add the `--plain` option for plain output on every command. ([#340](https://github.com/goldbarth/chartula/pull/340))
- Quote pull request titles and descriptions between `<title>` and `<description>` tags in the prompts, add a shared prompt rule that the quoted text is not instructions, and cut descriptions longer than 8,000 characters in the prompt only. ([#338](https://github.com/goldbarth/chartula/pull/338))
- Stop `generate` before the first model call when the tag's release is already published, unless `--replace-published` is passed. ([#335](https://github.com/goldbarth/chartula/pull/335))
- Make `doctor` name this version's configuration template when it finds no `chartula.yaml`. ([#329](https://github.com/goldbarth/chartula/pull/329))
- Show each step of a run (reading pull requests, rendering and checking each audience) on stderr while it works, through the new `IRunProgress` port. ([#297](https://github.com/goldbarth/chartula/pull/297))
- Add the `chartula doctor` command, which checks the setup a run needs and prints one status line per check. ([#295](https://github.com/goldbarth/chartula/pull/295))
- Take closed issue numbers for `linkedIssues` from the text the model reads at every depth, and read the old `factBase.depth` value `title-description-and-issues` as `title-and-description`. ([#293](https://github.com/goldbarth/chartula/pull/293))
- Render a commit that belongs to no merged pull request as its own change next to the pull requests, and skip merge commits without a pull request. ([#291](https://github.com/goldbarth/chartula/pull/291))
- Add `chartula --version`, which prints the installed informational version and exits with 0. ([#286](https://github.com/goldbarth/chartula/pull/286))
- Render a first tag from the first commit without a flag, remove `--whole-history`, and ask for confirmation before reading a first tag or a range above `range.confirmAboveCommits` commits. ([#282](https://github.com/goldbarth/chartula/pull/282))

### Fixed

- Compare the rule-based faithfulness check's names with whitespace folded and code fences removed, so names wrapped over lines or near fenced blocks are no longer flagged. ([#336](https://github.com/goldbarth/chartula/pull/336))
- Write a fixed sentence into `CHANGELOG.md` and the release notes when a release has nothing for the technical reader, instead of an empty heading. ([#333](https://github.com/goldbarth/chartula/pull/333))

- Print `unauthenticated, <VARIABLE> is not set` in the run header when a credential variable is unset or blank. ([#330](https://github.com/goldbarth/chartula/pull/330))

- Check before the first model call that the token may publish, using `POST releases/generate-notes`, so `generate` stops early instead of after every model call. ([#285](https://github.com/goldbarth/chartula/pull/285))
