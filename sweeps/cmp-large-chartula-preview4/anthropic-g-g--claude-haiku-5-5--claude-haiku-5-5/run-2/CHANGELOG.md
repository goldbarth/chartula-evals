## 0.1.0-preview.4 - 2026-10-07

### Changed

- This release will bump the NuGet minor and patch dependency group, updating Anthropic from 12.49.0 to 12.53.0, coverlet.collector from 10.0.1 to 10.1.0, and Microsoft.Extensions.AI.OpenAI from 10.10.0 to 10.10.1. ([#328](https://github.com/goldbarth/chartula/pull/328))

### Added

- **Breaking:** This release will stop writing the pull request description into changelog.json, which becomes schema version 2 and no longer carries a description field, while the run record gains an optional facts array holding the complete change entries with their descriptions. ([#294](https://github.com/goldbarth/chartula/pull/294))
- **Breaking:** This release will make preview free of model calls: it lists the facts, which audiences carry each one, each dropped change with the setting that dropped it, and the number of model calls and prompt characters generate would send, without reading the model or needing a key. ([#292](https://github.com/goldbarth/chartula/pull/292))
- This release will open each run's summary with a first line stating how the run went, such as generated, generated with review flags, partially generated, or no audience rendered, and will show each audience's name as a heading above its rendering. ([#342](https://github.com/goldbarth/chartula/pull/342))
- This release will group the doctor checks under Repository, Model and GitHub headings, mark each status with a symbol and a word, and state in its closing verdict whether a run would start or stop and which warnings limit it. ([#341](https://github.com/goldbarth/chartula/pull/341))
- This release will show each run step's progress with an animated spinner in a terminal, and will add a --plain option that disables colour, motion and non-ASCII output. ([#340](https://github.com/goldbarth/chartula/pull/340))
- This release will quote pull request titles and descriptions between tags in model prompts, cut descriptions longer than 8,000 characters, and tell the model that the quoted text is material to rephrase rather than instructions. ([#338](https://github.com/goldbarth/chartula/pull/338))
- This release will stop before the first model call when generate would replace the notes of an already published release, unless the new --replace-published option is given, and will report this in doctor as a warning. ([#335](https://github.com/goldbarth/chartula/pull/335))
- This release will name the location of this version's config template in the doctor output when no chartula.yaml is found. ([#329](https://github.com/goldbarth/chartula/pull/329))
- This release will show each step of a run while it works, reporting reading pull requests, rendering each audience and checking each rendering, with live timing in a terminal and plain lines otherwise. ([#297](https://github.com/goldbarth/chartula/pull/297))
- This release will add a doctor command that checks the setup a run needs, reporting ok, warn, fail or skip for each check, and exits with code 1 when a check fails. ([#295](https://github.com/goldbarth/chartula/pull/295))
- This release will read closed issue numbers from the title and description the model reads at every depth, and will accept the old factBase.depth value title-description-and-issues as title-and-description. ([#293](https://github.com/goldbarth/chartula/pull/293))
- This release will render commits that belong to no pull request as changes of their own, skip merge commits without a pull request, and report the commits without one in the run summary and run record. ([#291](https://github.com/goldbarth/chartula/pull/291))
- This release will print the installed version with chartula --version, showing the informational version that changelog.json records. ([#286](https://github.com/goldbarth/chartula/pull/286))
- This release will render a first tag from the first commit by default and ask for confirmation before reading a range of more than 200 commits or a first tag, with --yes to confirm in advance and --whole-history removed. ([#282](https://github.com/goldbarth/chartula/pull/282))

### Fixed

- This release will list each option once in chartula --help and will update the roadmap to reflect the completed launch items. ([#344](https://github.com/goldbarth/chartula/pull/344))
- This release will fold whitespace and remove code fences before the rule-based faithfulness check compares names, so names wrapped across lines or inside fenced blocks are no longer flagged when the facts contain them. ([#336](https://github.com/goldbarth/chartula/pull/336))
- This release will state in CHANGELOG.md and the release notes that a release has no features, fixes, performance improvements or breaking changes when the technical rendering is empty, without asking the model to write it. ([#333](https://github.com/goldbarth/chartula/pull/333))
- This release will write changelog.json and the run record with only the escaping JSON requires, so backticks, quotes and non-ASCII characters are readable in the files. ([#332](https://github.com/goldbarth/chartula/pull/332))
- This release will set the flagged-for-review block apart from the last entry of a rendering with a blank line and its own heading. ([#331](https://github.com/goldbarth/chartula/pull/331))
- This release will state unauthenticated with the variable name in the run header when GITHUB_TOKEN or the model key variable is unset or blank, instead of naming it as a token or key source. ([#330](https://github.com/goldbarth/chartula/pull/330))
- This release will check command-line options before a run starts, refuse options a command does not take with a suggestion of the closest match, honour --help after a command, and refuse a value option without a value. ([#301](https://github.com/goldbarth/chartula/pull/301))
- This release will add the missing trailing slash to a GitHub API base URL written without one, so requests reach the intended endpoint. ([#290](https://github.com/goldbarth/chartula/pull/290))
- This release will read an empty filter.excludeCategories list as dropping no category, instead of keeping the default Internal exclusion. ([#289](https://github.com/goldbarth/chartula/pull/289))
- This release will report a model answer the SDK cannot read as an unreadable answer from a reachable endpoint, naming the answer and the unreadable value, instead of as an endpoint that could not be reached. ([#288](https://github.com/goldbarth/chartula/pull/288))
- This release will refuse to run when both chartula.yaml and chartula.yml exist in the directory, naming both paths and how to resolve the conflict. ([#287](https://github.com/goldbarth/chartula/pull/287))
- This release will check before the first model call that the token may publish release notes, stopping the run early with the same message a refused publication gives, while preview and --no-publish skip the check. ([#285](https://github.com/goldbarth/chartula/pull/285))
- This release will describe --no-publish in the help text as writing every file while publishing no GitHub release notes. ([#284](https://github.com/goldbarth/chartula/pull/284))
